# Task R46-T013: Negation Precedence in Ada.gitignore

## Focus Patterns
- `*.o`
- `*.ali`

## Negation Precedence & Last-Match Semantics

Git evaluates ignore patterns sequentially from top to bottom. When an exclamation mark `!` prefix is used to negate an ignore pattern, Git follows "last matching pattern wins" semantics:

1. **Re-inclusion via Negation Order (`*.o` followed by `!prebuilt.o`)**:
   - When a general ignore rule `*.o` is followed by an explicit negation `!prebuilt.o`, Git first considers `prebuilt.o` ignored by `*.o`, but the subsequent negation `!prebuilt.o` overrides it.
   - Result: `prebuilt.o` remains visible and tracked in the repository, while other object files (e.g. `main.o`) remain ignored.

2. **Overridden Negation (`!prebuilt.o` followed by `*.o`)**:
   - If the negation pattern is placed *before* `*.o`, the later `*.o` pattern overrides the negation.
   - Result: `prebuilt.o` is ignored by rule `*.o`.

## Fixture Verification

### Positive Fixtures (Ignored)
- `main.o`: Object file at root (matches `*.o`).
- `build/sub.o`: Nested object file (matches `*.o`).
- `main.ali`: Ada Library Information file generated by GNAT (matches `*.ali`).
- `build/sub.ali`: Nested `.ali` file (matches `*.ali`).

### Negative / Near-Miss Fixtures (Visible)
- `main.adb`: Legitimate Ada body source file (must remain visible).
- `main.ads`: Legitimate Ada specification source file (must remain visible).
- `prebuilt.o.txt`: Text file ending in `.txt` rather than `.o`.
- `data.ali.bak`: Backup file ending in `.bak`.

## Tracked Files Behavior
Files already tracked by Git prior to applying ignore rules remain tracked. Modifications to tracked `.o` files are still detected and reported by `git status --porcelain`.
