# Task R46-T017: Pattern Origin in OpenCart.gitignore

## Focus Patterns
- `.htaccess`
- `/config.php`
- `admin/config.php`

## OpenCart Architecture: Source Templates vs Runtime Outputs

In standard OpenCart distributions (per official OpenCart documentation and release packages):
1. **Source Templates (Distributed in Git & Must Remain Visible)**:
   - `htaccess.txt`: Distributed Apache rewrite rules template.
   - `config-dist.php`: Distributed storefront configuration template containing default placeholders.
   - `admin/config-dist.php`: Distributed administration backend configuration template.
   - Core framework configuration files such as `system/config/default.php`.

2. **Runtime / Tool Outputs (Created During Installation & Must Be Ignored)**:
   - `.htaccess`: Created/renamed from `htaccess.txt` during Apache setup. Contains host-specific RewriteBase and directory directives.
   - `/config.php`: Generated by the OpenCart web setup wizard (`install/index.php`) at step 3. Stores production database credentials (DB_HOSTNAME, DB_USERNAME, DB_PASSWORD, DB_DATABASE), encryption keys, and absolute server storage paths (`DIR_STORAGE`).
   - `admin/config.php`: Generated by the installer for the administrative backend. Stores admin-specific session handlers, catalog links, and admin directory mappings.

3. **Anchoring & Pattern Behavior**:
   - `.htaccess`: Unanchored pattern (no slashes), ignores `.htaccess` files across both root and subdirectories (`admin/.htaccess`).
   - `/config.php`: Anchored to the repository root. Does not match nested configuration modules like `system/config.php`.
   - `admin/config.php`: Anchored to the `admin/` directory.

## Fixture Verification

### Generated Runtime Outputs (Ignored)
- `.htaccess`: Root server configuration (matches `.htaccess`).
- `admin/.htaccess`: Backend server configuration (matches `.htaccess`).
- `config.php`: Root storefront configuration (matches `/config.php`).
- `admin/config.php`: Admin backend configuration (matches `admin/config.php`).

### Legitimate Source Templates & Near Misses (Must Remain Visible)
- `htaccess.txt`: Official source template file (visible).
- `config-dist.php`: Official distributed template for root config (visible).
- `admin/config-dist.php`: Official distributed template for admin config (visible).
- `system/config.php`: Sibling core configuration file (visible).
- `catalog/config.php`: Other subdirectory configuration (visible).

## Tracked Files Behavior
Files tracked in Git prior to applying the template (such as an existing committed configuration) remain tracked and monitored. Modifications are reported by `git status --porcelain`.
